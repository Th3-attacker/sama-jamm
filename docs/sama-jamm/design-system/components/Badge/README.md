# Badge

Étiquette courte qui donne un état : téléchargé, nouveau, bientôt atteint, dépassé.

- **Le consommateur fournit** : le mot en `children`, un `ton`, éventuellement une `icone` de 14 px.
- Tons : `neutre` (date, durée), `emeraude` (disponible hors ligne, terminé), `or` (nouveau, mis en avant), `alerte` (plus de 85 % d'une enveloppe), `erreur` (dépassé, échec).
- Le sens est toujours porté par le mot, la couleur ne fait que le confirmer. Contraste du texte ≥ 4,5 dans les trois thèmes.
- Hauteur 22, rayon `rayon-puce`, texte 12/16 graisse 600.
- À ne pas faire : pastille rouge de notification sur un onglet, chiffre seul sans mot, plus de deux badges sur une ligne.
