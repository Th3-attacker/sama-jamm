# Banner

Message qui reste en place en haut d'un écran tant que la situation dure : hors ligne, Veille active, position refusée.

- **Le consommateur fournit** : `ton`, `titre`, le texte en `children`, éventuellement `action` et `onFermer`.
- Tons : `attention` (hors ligne, fond `or-doux`), `veille` (fond `surface-creux`, lune `or-texte`), `info` (fond `emeraude-doux`), `erreur` (contour `erreur`, fond `surface`), `succes`.
- Le texte dit ce qui marche encore et quoi faire : « Les horaires et vos sourates téléchargées restent disponibles. »
- Placé sous la barre du haut, jamais par-dessus le contenu de lecture.
- À ne pas faire : plus d'un bandeau à la fois, bandeau publicitaire, ton `erreur` pour une information.
