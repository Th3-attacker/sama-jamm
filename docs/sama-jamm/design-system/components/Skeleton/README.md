# Skeleton

Silhouettes grises qui tiennent la place du contenu pendant un chargement de plus de 300 ms.

- **Le consommateur fournit** : `forme` (`liste` ou `carte`), `lignes`.
- Blocs `surface-creux` qui respirent doucement (opacité 1 → 0,55 en 1,6 s) ; immobiles si « Réduire les animations » est activé.
- La plupart des écrans n'en ont pas besoin : textes et horaires sont sur le téléphone. Usages : catalogue des récitateurs, synchronisation, khatm partagé.
- À ne pas faire : spinner plein écran, squelette pour un contenu déjà en cache.
