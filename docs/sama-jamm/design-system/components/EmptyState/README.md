# EmptyState

Écran vide accueillant : « Jàmm rekk », rien ici pour l'instant, en paix, et ce qu'il faut faire pour le remplir.

- **Le consommateur fournit** : `titre` wolof court, `sousTitre` (sa traduction), `texte` (l'action qui remplira l'écran), `icone`, `action`.
- Étoile à huit branches `or-doux` cerclée d'`or`, icône `or-texte` au centre ; titre Cormorant émeraude.
- Exemples : Favoris (« Touchez le signet d'un verset… »), Téléchargements, Historique du budget (« Ajoutez votre première dépense »), Recherche sans résultat (« Aucun verset ne contient… »).
- À ne pas faire : illustration de personnage, ton culpabilisant (« Vous n'avez encore rien lu »).
