# SavingsGoal

Un objectif d'épargne avec son intention (niyya) : Tabaski, urgence, oumra.

- **Le consommateur fournit** : `nom`, `intention` (écrite par l'utilisateur), `epargne`, `objectif` (facultatif), `echeance`, `icone`, `conseil`.
- Montant épargné en 24 gras, « sur … » à côté ; barre `or` avec le pourcentage écrit ; sans objectif chiffré, pas de barre.
- L'intention en italique sous le nom rappelle pourquoi on met de côté.
- À ne pas faire : intérêts ou rendement (riba), comparaison avec d'autres foyers.
