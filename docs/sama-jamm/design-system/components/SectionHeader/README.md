# SectionHeader

Titre de section bilingue : le mot wolof en Cormorant, sa traduction en italique dessous.

- **Le consommateur fournit** : `titre`, `lang` (« wo » si le titre est wolof), `sousTitre`, éventuellement `action` (« Tout voir »).
- Titre `titre-2` (Cormorant 24, jamais plus petit), sous-titre `translitteration`.
- C'est la signature de la voix de Sama Jàmm : « Wax ju rafet · Sagesse du jour », « Benn loxo du tàccu · Une seule main ne peut pas applaudir ».
- Espacement : `espace-8` avant, `espace-3` après.
- À ne pas faire : titre en majuscules, plus de trois mots en wolof sans traduction.
