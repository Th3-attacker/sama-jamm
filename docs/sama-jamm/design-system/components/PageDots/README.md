# PageDots

Indique l'étape des écrans de bienvenue (trois étapes : langue, position, rappels).

- **Le consommateur fournit** : `total` et `actif` (index à partir de 0).
- Étape en cours : pastille allongée `emeraude` de 24 × 8 ; étapes faites : points `or` ; étapes à venir : points `ligne-forte`.
- Lu comme « Étape 2 sur 3 ».
- Ce n'est pas un bouton : on avance par le bouton principal, on recule par « ← ».
