# BeadThread

Le fil de régularité : un grain par jour du mois, doré les jours de lecture, sans série à perdre.

- **Le consommateur fournit** : `jours` (`fait`, `aujourdhui`), `titre`, `resume` (« 12 jours de lecture en octobre »).
- Grains de 8 px sur un fil `ligne` : lus en `or`, autres en `surface-creux`, aujourd'hui cerclé d'`emeraude`.
- Le résumé compte ce qui a été fait, jamais ce qui manque : pas de « série perdue », pas de flamme, pas de rappel culpabilisant.
- Le mois suivant repart à zéro sans message.
- À ne pas faire : compteur de jours consécutifs, classement entre utilisateurs.
