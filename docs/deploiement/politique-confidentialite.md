# Politique de confidentialité – Sama Jàmm

Dernière mise à jour : **À VALIDER (date de publication)**
Éditeur : **À VALIDER (nom, pays)** · Contact : **À VALIDER (email)**

Sama Jàmm est gratuite et sans publicité. Elle n'utilise aucun outil de mesure d'audience ni de suivi publicitaire.

## 1. Ce qui reste sur votre téléphone
- **Budget du foyer** : revenus, dépenses, enveloppes, zakat. Ils sont stockés dans une base chiffrée sur l'appareil et ne sont jamais envoyés. Vous pouvez en exporter une copie vous-même (fichier de sauvegarde) ; son partage dépend de vous.
- **Position** : utilisée seulement quand l'app est ouverte, pour les horaires de prière et la qibla. Le calcul se fait sur le téléphone ; la position n'est pas envoyée.
- **Réglages, lecture, favoris, dhikr, progression** : stockés sur l'appareil.
- **Verrou du budget** : Face ID / empreinte / code gérés par le système ; l'app ne reçoit pas vos données biométriques.
- **Rappels de prière** : notifications programmées sur le téléphone, sans serveur de notifications.

## 2. Ce qui est envoyé à nos serveurs (Supabase)
Seulement si vous utilisez ces fonctions :
- **Compte** (facultatif) : identifiant du compte, adresse email fournie par Google ou Apple (Apple peut la masquer), prénom facultatif.
- **Khatm collectif** : nom, intention, échéance, juz pris et leur état, prénom affiché aux membres du même khatm.

Chaque table est protégée par des règles d'accès : chacun ne voit que ses données, et les khatms ne sont visibles que de leurs membres.

## 3. Services tiers
- **Google / Apple** : connexion. Aucun mot de passe ne passe par l'app.
- **Supabase** (hébergement du compte et du khatm) : région d'hébergement **À VALIDER**.
- **Islamic Network (cdn.islamic.network)** : lecture en ligne des récitations. Ce service voit l'adresse IP de l'appareil.
- **GitHub Pages** : l'app lit un fichier de version pour proposer une mise à jour. L'adresse IP est visible de l'hébergeur.
- **Expo (EAS Update)** : livraison des mises à jour de l'app. **À VALIDER** (données techniques transmises).

## 4. Vos droits
- **Supprimer votre compte** : Plus › Réglages › Supprimer mon compte. Votre profil et vos participations sont effacés ; les parts de khatm que vous avez prises redeviennent sans titulaire.
- **Supprimer le budget** : supprimer l'app ou utiliser la fonction d'effacement des données de l'app **À VALIDER (existence de l'écran)**.
- Pour toute demande (accès, rectification, effacement) : écrire à l'adresse de contact. Délai de réponse **À VALIDER**.

## 5. Enfants
L'app n'est pas destinée à collecter des données d'enfants. Âge minimal pour créer un compte : **À VALIDER**.

## 6. Conservation et sécurité
Les données du compte sont conservées jusqu'à suppression du compte. Les échanges sont chiffrés (HTTPS).

## 7. Modifications
Toute modification sera publiée à cette adresse avec une nouvelle date.
